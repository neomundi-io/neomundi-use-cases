# NeoMundi Use Cases

Documented use cases, interoperability pilots and experimental articulations using NeoMundi runtime measurement signals.

NeoMundi provides a measurement layer.  
The systems presented here retain their own architecture, governance logic, operational authority and implementation choices.

## Scope

These repositories document concrete integrations, pilots and experimental articulations around NeoMundi signals.

They are intended to make observable:

- how NeoMundi measurements are consumed;
- how independent systems can articulate around a common measurement layer;
- how responsibilities remain separated between measurement, governance, evidence and application layers;
- what has actually been tested;
- the limits of each experiment.

These use cases do not imply that NeoMundi validates, certifies or governs the partner systems.
